# ValveBench 0.1.20-dev3 — reviewfix2

Адресные исправления по повторному разбору Gain Match. Базой является пользовательский
`ValveBench-0.1.20-dev3-reviewfix.tar.gz`; номер версии приложения не менялся.

## Изменения

### SINAD и тест T1

- Исправлена генерация тестовых гармоник: H2=−32 dBc и H3=−40 dBc теперь задаются
  относительно несущей −20 dBFS, а не как абсолютные −32/−40 dBFS.
- T1 проверяет численный SINAD независимым расчётом мощности. Для заданного сигнала
  Live и независимый референс дают 31.36 dB.
- C2 дополнительно проверяет реальную подпись в `gainview.py`: пользователь видит SINAD,
  а не SNR. Совместимое внутреннее поле `snr_db` пока остаётся алиасом.

### Сетевые гармоники в Live и Static

- `mains_proximity_warnings()` формирует ближайшую безопасную альтернативу динамически
  по фактической частоте сети, а не только из списка 50-Гц профиля. Работает для 50 и 60 Гц.
- LivePage выводит заметное предупреждение рядом с фактически поданными параметрами
  генератора, если тон близок к гармонике сети (порог 6 бинов при df=1 Гц).
- Static series сохраняет предупреждения в отчёте; проверка 9994 Гц против 200-й
  гармоники сети 49.97 Гц остаётся в регрессии.
- Предупреждение не объявляет помеху измеренной и не пытается «вычесть» неразличимую
  линию из несущей. Для точного совпадения тон и сетевую линию спектрально разделить нельзя.

### Производительность GainTracker

- Для выбора между номинальной и оценённой частотой используется более дешёвая LSQ-подгонка
  основной гармоники. Полный H1…H9 базис создаётся только для выбранной частоты, а не для
  каждого кандидата.
- Матрица гармонического базиса заполняется на месте; убраны список временных массивов
  и дополнительный `column_stack` на cache miss.
- Тест производительности измеряет серию cache hit, p50/p95/p99 и максимум отдельно.
  Критерий miss привязан к 75-мс GUI-тику; это не тест задержек аудиодрайвера.

## Не менялось

- Формула SINAD в измерительном коде: разбор показал, что прежние 11.4 dB в T1 были
  математически правильны для фактически сгенерированных тогда гармоник −12/−20 dBc.
  Ошибка находилась в тестовом сигнале и его подписи, а не в SINAD-вычислителе.
- Правила валидности C/R, TARE, RIAA-компенсация, обработка XRUN и алгоритмы Peak Hold.
- Никакие аппаратные устройства не открывались и не тестировались.
