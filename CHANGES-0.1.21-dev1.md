# ValveBench 0.1.21-dev1 — выгрузка измерений DUT и отдельный ADC PAD

База: `0.1.20-dev3-reviewfix4.2`.

## Что добавлено

- В верхнюю панель добавлены поле номера аппарата, заметка и кнопка `СОХРАНИТЬ ЗАМЕР`.
- Каждый сохранённый результат создаёт неизменяемую сессию в `measurements/devices/<ID>/<timestamp>-<kind>/`.
- `session.json` хранит полную числовую структуру результата, заметку и снимок контекста: версию программы, ALSA-карту/устойчивый ID, PCM, Fs, форматы, mixer fingerprint, калибровки DAC/ADC, маршруты и PAD DUT→ADC.
- Создаются `metrics.csv`, `curves.csv`, `README.txt` и `MANIFEST.json` с SHA-256/размерами. JSON остаётся первичным форматом; NaN/Inf записываются как `null`.
- Повторные замеры не затирают прежние. ID валидируется; симлинк каталога устройства, ведущий наружу, отклоняется. Путь по умолчанию вычисляется относительно каталога приложения, поэтому запуск из чужого CWD не отправит файлы в домашний каталог.
- ID аппарата фиксируется при старте измерения; если перед сохранением его поменяли, экспорт просит вернуть исходный ID или повторить тест. Новый запуск измерения очищает старый экспортируемый результат, чтобы не сохранить прежние данные под чужим номером.
- Для Gain Match сохраняется DUT-result второго шага; петлевой эталон звуковой карты не предлагается как измерение DUT.
- В калибровке появился отдельный `adc_att_db` (PAD DUT→ADC), не смешанный с `att_db` (аттенюатор DAC→DUT). Поправка напряжения переводит показание обратно к выходу DUT.
- Профиль АЧХ/фазы привязан к конфигурации PAD. При смене делителя старая частотная поправка не применяется.

## Ограничения

- Импорт сессий, A/B-сравнение нескольких устройств и графики сравнения пока не реализованы.
- Универсальный экспорт не записывает исходный WAV/PCM для каждого теста. Он сохраняет полный объект результата и его численные массивы. Отдельная опция raw capture будет последующим этапом.
- В текущей среде нет GTK/PyGObject и реальных ALSA-карт, поэтому GUI-взаимодействие, физическая калибровка, реальный PAD и аудио-E2E не проверены. Приложение прошло синтаксическую проверку и полный DSP/симуляционный selftest.

## Проверки этой рабочей версии

- `python3 -m compileall -q valvebench` — PASS.
- `python3 -m valvebench selftest` — **103/103 PASS**, 0 FAIL.
- `python3 -m valvebench --version` — `ValveBench 0.1.21-dev1`.
- Экспортный selftest проверяет JSON/CSV, пропуски в кривых, manifest SHA-256, уникальность путей, вредоносный ID и symlink escape.
- ADC PAD tests проверяют профиль на нескольких картах, пересчёт напряжения и loopback с тем же PAD.
- В экспортном тесте дополнительно проверяется путь относительно каталога приложения, а не CWD.
- Чистая распаковка архива и повторное прохождение selftest зафиксированы в `REPORT-MEASUREMENT-EXPORT-0.1.21-dev1.md`.
