# ValveBench 0.1.17 — Page scrolling

## Исправление компоновки окна

В 0.1.16 элементы некоторых страниц размещались ниже видимой области окна, но прокрутка
была только у левой колонки параметров отдельных приборов. Правая колонка с графиком,
результатами и пояснениями, а также страницы Live и Spectrum целиком не имели общего
вертикального контейнера прокрутки.

В 0.1.17:

- все страницы семейства `Page` прокручиваются целиком по вертикали;
- главная страница Gain Match / Уровень прокручивается целиком, обе колонки вместе;
- страница большого FFT-спектра прокручивается целиком;
- вертикальная полоса прокрутки не накладывается поверх содержимого и появляется при
  переполнении;
- горизонтальная прокрутка отключена, чтобы не вводить вторую ось навигации;
- боковая панель вкладок и верхняя панель устройства/частоты остаются закреплёнными;
- сохранены исходные объекты страниц в Gtk.Stack — маршрутизация задач, статусы,
  переключение Live/Spectrum и сохранение параметров не меняют идентичность страниц.

## Проверки

- `python3 -m py_compile valvebench/*.py` — PASS.
- `./run.sh selftest` — 71/71 PASS.
- Проверена статическая структура: все типы страниц, используемые в Gtk.Stack
  (Page, LivePage, SpectrumPage), монтируют основной контент через `vertical_page_scroller`.
- GTK4/PyGObject в среде сборки отсутствуют, поэтому визуально проверить полосу прокрутки
  в запущенном окне здесь невозможно. Окончательная проверка поведения выполняется на
  Ubuntu-пользователя.
