# 0.1.8 — A/B-паспорт для доработки железа

## Новое: одна команда «лучше или хуже»
    # до правки (все частоты, ≈2–3 мин):
    ./run.sh cli passport --label before --rates 96000,176400,192000
    # быстрая проверка после каждой правки (одна частота, −1 dBFS, ≈45 с) со сравнением:
    ./run.sh cli --rate 192000 passport --quick --label try1 --compare passport-before.json
    # сравнить любые два паспорта:
    ./run.sh cli compare passport-before.json passport-try1.json
    # живой монитор для пайки/пинцета (остаток L и R каждые ≈1.5 с, Ctrl+C — выход):
    ./run.sh cli --rate 192000 watch --baseline passport-before.json

Паспорт (на каждый канал АЦП): шум тишины 20–20k / 20k–40k / 40k–Fs/2, A-вес, фон 50 Гц, DC,
линии-спуры; с тоном 997 Гц на −1 и −12 dBFS — уровень, H2/H3, негармонический остаток
(медиана, min…max, разброс), его раскладка по полосам и главные линии с отстройкой от тона;
проникновение L↔R. Каждый повтор — отдельное открытие карты: разброс между открытиями входит
в критерий, поэтому случайное тихое измерение не выдаётся за улучшение.
Главные строки: «остаток с тоном», «разброс остатка», «индекс аномалии» (превышение остатка над
шумом тишины, у исправного канала ≈ 0 дБ, и асимметрия L−R).

## Исправления
* Живой спектр, плотность шума: асимметричное сглаживание attack/release завышало полку на ≈2 дБ
  (проверено на модели). Теперь для PSD оно симметричное. Остальное расхождение (скриншот ≈ −148,
  Welch ≈ −153,6) проверяется командой `cli psdcheck`.
* levelscan: точки с разбросом > 3 дБ получают kind=unstable вместо «не зависит от уровня».
* loopback: SERIES VALIDITY теперь OK / INVALID / INCOMPLETE (--silence-seconds 0 даёт INCOMPLETE);
  XRUN/underrun/overrun в тоновых прогонах → INVALID.
* «noise-only» переименовано в «негармонический остаток» (шум + боковые полосы + посторонние линии).
* Страница THD в GUI: частота по умолчанию 997 Гц.
