# 0.1.5 — исправления когерентного анализатора и Gain Match

## Анализ гармоник
- Когерентный режим теперь нормирует фазу каждой гармоники на фазу фундаментального тона для каждого блока (`phase_h - h*phase_1`).
- Фазовый сдвиг между границами блоков больше не должен гасить фундамент/гармоники при усреднении.
- В отчёт добавлены phase coherence и явное различение THD обнаруженных линий, частичного набора и сырой суммы гармонических бинов.
- Порог однобиновой линии повышен с 6 до 10 dB для снижения ложных срабатываний при множественных проверках.
- Некогерентный режим теперь усредняет спектральные мощности, а не временные блоки; это исключает фазовое взаимопогашение.
- В профиль тишины добавлен поиск устойчивых фазово-когерентных линий на тех же DFT-бинах, что и гармоники. Их мощность включается в порог обнаружения, а не маскируется как случайный широкополосный шум.
- Порог когерентности профиля тишины зависит от числа блоков: при короткой записи он строже, чтобы случайный шум не принимался за устойчивый spur.
- Сравнение ±5 Hz оставлено отдельной широкой диагностикой; отчёт прямо предупреждает, что его нельзя напрямую сравнивать с однобиновым порогом.
- Loopback CSV теперь сохраняет raw dBc, общий/случайный floor и мощность устойчивой линии из baseline.
- Loopback CLI печатает `≤` для линий ниже внутреннего порога.

## Gain Match
- Сбрасывается устаревшее значение ΔG при остановке/невалидном маршруте.
- Индикатор не выдаёт результат при SNR ниже 15 dB.
- Повторная команда tare теперь устанавливает ноль по текущей ΔG, а не накапливает поправку.

## Тесты
- Добавлены проверки сохранения H2/H3 при фазовом дрейфе между блоками.
- Добавлена проверка, что чистый тон с шумом не порождает достоверные гармоники.
- Добавлены проверки обнаружения устойчивого 3-кГц spur в записи тишины, отбраковки случайного шума и корректного gating слабой/сильной H3 относительно baseline spur.
- Самотест: 20/20.
