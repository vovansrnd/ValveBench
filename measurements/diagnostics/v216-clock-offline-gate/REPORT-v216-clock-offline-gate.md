## Ответ на главный вопрос

**Нет — R-only onset НЕ даёт полноценного успешного clock-check.**

1. SNR-гейт (≥ 20 дБ, carrier-local) проходят ОБА канала во всех четырёх
   захватах (L 26.3–36.0, R 33.4–52.9) — последующий SNR не блокирует.
2. Устойчивость окон: `window_stability_reason = None` везде — не блокирует.
3. **Блокирует межканальное согласование ppm**: в окнах от R-only onset
   gate FALSE в 2 из 4 захватов (spread 7.54 и 6.15 > 5 ppm). Два «прохода»
   (idx 15, 16) — впритык (3.57 и 4.53 из 5 допущенных) и за счёт
   НЕНАДЁЖНОЙ оценки L: её значения −27.81 и −18.72 отклоняются от R/консенсуса
   на 3.6–4.5 ppm — проход случаями, не надёжностью.
4. Практическое следствие для production: правка только onset-детектора
   превратила бы clock_check(−72/−66) в «иногда ok=True» с мусорной оценкой
   L (±4–8 ppm от истины) — формально успешное, но недостоверное измерение.
   Достоверную оценку такта на этих уровнях даёт только канал R
   (±0.7 ppm на всех уровнях).

## Исправления по ревизии v2.15 (внесены в отчёт v2.15, commit f94d51a)

* Запас R над собственным порогом на −72: **7.9 дБ** (asc) и **9.9 дБ** (desc),
  не 18.0/17.9 — перепутаны с константой 8× = +18 дБ правила порога.
* 16-дБ разница каналов названа **наблюдаемой**; физическая природа
  (кабель/линия/карта) не установлена.
* Прохождение onset отделено от прохождения последующего clock-gate —
  данный отчёт и есть эта проверка.

## Итог для решения координатора

* **Одной правки onset-детектора недостаточно** для достоверного
  clock-check на −72/−66: после неё включается следующий барьер —
  ненадёжная оценка ppm канала L (spread-гейт 5 ppm проходит/отваливается
  случайно).
* Достоверные варианты на этих уровнях: clock по одному каналу R
  (изменение семантики production — решение координатора), либо повышение
  уровня пилота для прямой линии (−42…−30 надёжны по v2.14), либо
  уровень, безопасный для конкретного DUT, — отдельная настройка.
* Стабильность окон (None) подтверждена: структурных препятствий под
  этими окнами нет, отказы — чисто числовые гейты.
* Аппаратных измерений не проводилось; `main`, PR #4, production не тронуты.
