# v2.26.2 — coordinator review

## Verdict

**Главный критерий FAIL.** v2.26.2 требовал полный PASS на −24 dBFS во всех
трёх независимых сессиях. Получено 2/3 PASS; в run-03 один repeat
ослабленного L на 9994 Hz получил C/R=29.606592 dB при пороге 30.0 dB.

Это не ошибка численной коррекции Gain Match: corrected ΔG во всех 36
инъекционных строках отклонился от цели не более чем на 0.0052 dB.
Отказ происходит на production-гейте C/R.

## Подтверждённые результаты

- Офлайн: py_compile OK, D0 11/11, D1 6/6; integrations выполнены;
  selftest PASS.
- Физический маршрут: D10 playback hw:1,0 → E-MU capture hw:2,0, 192 kHz.
- Три независимые сессии завершены последовательно.
- −24 dBFS: run-01 PASS, run-02 PASS, run-03 FAIL.
- −18 dBFS: run-01 FAIL (один envelope outlier), run-02 PASS, run-03 PASS.
- В каждом run манифест содержит 18 записей: 8 NPZ captures + 10 JSON.
  Агент сообщает независимую проверку 18/18 для каждого run.
- Всего 24 captures (8 × 3); агент сообщает 0 NaN / 0 Inf в аудиомассивах.
  В двух preflight NPZ каждой сессии присутствует ожидаемый NaN sentinel
  только в метаполе generator_level_dbfs.
- Fatal hardware events и clipping не зарегистрированы; mixer fingerprint
  одинаковый между сериями.

Верхний run-summary статус harness означает PASS, если прошёл хотя бы один
уровень. Поэтому run-03 имеет верхний PASS, хотя m24 FAIL, а m18 PASS.
Итог v2.26.2 определён по отдельному главному критерию −24 во всех трёх runs.

## Почему −24 нестабилен

В run-03 / −24 / inject-L / 9994 Hz / L / repeat 1:
- carrier level ≈ −59.2054 dBFS;
- residual noise ≈ −88.8120 dBFS;
- C/R = 29.606592 dB;
- low_carrier_residual; envelope z_burst=2.063 (не burst/outlier).

В соседних повторах той же строки carrier остаётся около −59.204 dBFS,
а residual noise лежит примерно −90.15 и −89.77 dBFS. Это указывает на
подъём остаточного шума примерно на 1.0–1.3 dB, а не на изменение carrier
или ошибку ΔG. Источник изменения не установлен; его нельзя приписывать
конкретному устройству внутри маршрута D10→E-MU.

Худший individual-repeat C/R ослабленного L на 9994 Hz по трём run-ам:
30.859618 / 30.770193 / 29.606592 dB. Запас к 30 dB:
+0.860 / +0.770 / −0.393 dB.

## Envelope observations at −18 dBFS

В run-01 / inject-L / 9994 Hz / R / repeat 1: unstable_carrier,
z_burst=5.01693, несмотря на C/R≈62.50 dB. В предыдущем v2.26.1 r1 был
другой единичный envelope event: R / 94 Hz / repeat 2, z_burst≈5.8123.
В v2.26.2 событие на 94 Hz не повторилось, но событие на R появилось
на другой частоте. Это пока не доказывает периодичность.

## Следующий эксперимент

−24 dBFS не квалифицирован как надёжная рабочая точка. −18 dBFS показал
больший C/R запас, но прошёл только 2 из 4 аппаратных сессий с учётом r1
из-за разных единичных envelope events. Следующий ограниченный кандидат —
−20 dBFS: промежуточный уровень, который должен дать больший C/R запас
относительно −24 без перехода к −18. Это только гипотеза для проверки,
не утверждение о результате и не изменение production default.
