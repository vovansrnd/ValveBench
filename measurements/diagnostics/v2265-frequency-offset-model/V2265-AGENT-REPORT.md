## 4. Классификация событий (по схеме задания)

- **A, C (94 Гц): not explained by detuning; отказ воспроизводится
  residual-компонентой** — pure-tone при том же (микроскопическом)
  detuning даёт z≈1.1/0.97, а фиксированный commanded-фундаментал +
  residual даёт z 5.20/5.63 ≈ фактических. Возмущение содержится в
  residual записи.
- **B, D, L-9994, loopback-9994: not explained by detuning alone;
  механизм совместный** — pure-tone даёт z≈0.9–1.2 (даже при
  Δf≈−0.25 Гц), но фактический сигнал (фундаментал на measured f +
  residual) даёт полные z, а замена фундаментала на commanded-копию
  residual-контроль снижает z до 1.3–2.8. Полный отказ требует
  фактического фундаментала И residual; ни одна компонента по
  отдельности порога не достигает.

**Итог: частотное рассогласование commanded-vs-measured НЕ способно
само вызвать unstable_carrier (максимум z≈1.2 на чистом тоне при
фактических offset до −0.25 Гц). Реальный ADC capture содержит
дополнительную компоненту (residual 1.1–4.4% RMS фундаментала,
выбросы подокон до 25% амплитуды), которая и создаёт отказ — в
сочетании с фактическим фундаменталом на measured f.**

## 5. Ограничения

- Синтетический чистый тон — не физическая модель DAC/ADC; источник не
  определяется.
- residual — не «физический шум устройства»: смесь гармоник, шума,
  distortion, fitting/timing/ADC-артефактов.
- Production (командная частота, пороги Z_BURST_MAX=5.0/TREND_MAX=0.005,
  subwindow 0.1 с) не менялся и новых порогов не предлагается.
- Выборка — 324 окна четырёх исторических run-ов; вероятности не
  выводились.
- Offline-only: без устройств; воспроизводимость — командой из отчёта
  на том же pinned tree.
