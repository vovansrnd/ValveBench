# v2.23.0 — agent technical report (rerun, ИСПРАВЛЕН по ревизии v2.23.0)

Все три координаторских теста выполнены на pinned SHA 0a18994 без правок
(первый NameError-блокер устранён автором: OFFBAND_OFFSET_HZ = 500.0;
failed-run сохранён на agent/v2230-coordinator-authored-validation,
9328778). Настоящая редакция исправляет трактовки A/B/C по замечаниям
ревизии координатора; результаты тестов не пересчитывались.

## A. Narrowband occupancy (34 case)

* Комбинированный кандидат (margin ≥10 дБ + occupancy ≥0.97 + max run
  ≤50 мс) прошёл **10 из 34**; **все 15 случаев, отвергнутых
  Rig.run(), кандидат тоже отверг**; ещё **9 production-accepted
  случаев кандидат отверг** — среди них tail-провалы на −72 дБFS:
  production пропускает даже 800 мс отсутствия пилота, кандидат
  отклоняет.
* **noise_only НЕ проходит occupancy ≥0.97**: поблочные occupancy
  L 0.894/0.845, R 0.837/0.817 (все четыре ниже 0.97). Критерий
  максимальной паузы шум действительно пропускает (max run 18/10 мс),
  но occupancy и margin его отсекают. Итог: false pass шум-онли по
  комбинированному кандидату — 0.
* margin ≥20 дБ один не разделяет gapped-случаи (True почти всюду),
  но отсекает noise-only.
* L/R: различий кандидатов нет (steady −72: margin 29.8/29.9 дБ).
* Базовый уход −23.5 ppm виден в production (−23.1 ppm L). ±100 ppm:
  −100 ppm → clock_ok=False (|ppm|>100 с учётом базового −23.5),
  +100 ppm → True — корректная асимметрия допуска.

## B. 1000 Гц утечка и альтернативные пилоты (544 испытания)

* **Реальный эффект утечки мал**: максимальный парный сдвиг по
  leakage_cells на наблюдаемых уровнях — **≈0.35 ppm (L)** и
  **≈0.056 ppm (R)** (L: −109 дБFS, максимум по длительностям 0.323–0.349;
  R: −125 дБFS, максимум 0.051–0.056). L/R-сдвиги **не идентичны**
  (различаются и медианы, и максимумы: например −90 дБc стресс на
  1000 Гц 2 с: L median 2.07/max 3.18, R median 2.08/max 3.19).
* **Эффект длительности НЕ монотонен**: на 1000 Гц при стресс-утечке
  −90 дБc увеличение 2 → 6 с **увеличило** медианный сдвиг
  2.07 → 2.86 ppm. У 997 Гц — уменьшил (1.71 → 0.26), у 1013 Гц —
  уменьшил (0.65 → 0.03).
* **1013 Гц материально избегает эффекта**: 0.65 ppm (2 с) против
  2.07 у 1000 Гц при стрессе; на 6 с — 0.03 ppm.
* **Все 544 строки line_contaminated** — но это НЕ измерение
  детекции line-QC утечки 1000 Гц: во всех записях присутствует
  60 Гц линия гребёнки (−16 дБc), которую QC и флагает; в AM-контролях
  флагаются боковые. Вывод о детекции именно утечки из этих статусов
  не следует.
* **nearby_probe_hits = 0/544 не доказывает ничего об утечке**:
  при пилоте 1000 Гц утечка отстоит всего на 0.0235 Гц (внутри
  исключённого ядра ±0.3 Гц); при 997/1013 Гц она вне зоны поиска
  ±1.5 Гц. Проба на фактическом смещении утечки не проверена.
* **AM/FM контроли (48)**: nearby-пробник ни разу не сработал —
  наивное «nearby-hit = reject» не отбраковало бы легитимную
  модуляцию. Но full-window line-QC флагает AM-боковые
  (±5/±20 Гц, −12 дБc) — «line-hit = reject» отбраковал бы АМ.

## C. Независимая локальная PSD / CRLB (384 испытания)

* Медиана |fit error| относительно CRLB — **0.61–0.85** по ячейкам
  (2/4/6 с × white/colored): оценка LSQ состоятельна и близка к
  границе;
* **L/R корреляция ошибок 0.92–0.97** во всех ячейках (коррелированный
  шум 0.95): **независимость ошибок каналов предполагать нельзя**,
  объединение L/R не даёт √2;
* **Новая находка ревизии: собственная estimator_sigma согласуется с
  CRLB на белом шуме, но на цветном составляет лишь 0.26–0.27 CRLB —
  занижает неопределённость ≈ в 3.7–3.9 раза.** При этом фактическое
  std ошибок цветного шума близко к оценке по локальной PSD.
  Причина — мгновенный 2×2 whitening не белизнит временну́ю
  корреляцию (ограничение архитектуры, отмеченное в v2.21.0);
* статусы: ok 384/384 (60 Гц гребёнка в этот тест не включена).
