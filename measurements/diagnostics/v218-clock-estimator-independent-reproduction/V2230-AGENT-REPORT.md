## A. Narrowband occupancy (34 case)

* Комбинированный кандидат (margin ≥10 дБ + occupancy ≥0.97 + max run
  ≤50 мс) прошёл **10 из 34**; **все 15 случаев, отвергнутых
  Rig.run(), кандидат тоже отверг**; ещё **9 production-accepted
  случаев кандидат отверг** — среди них tail-провалы на −72 дБFS:
  production пропускает даже 800 мс отсутствия пилота, кандидат
  отклоняет.
* **noise_only НЕ проходит occupancy ≥0.97** — поблочные значения:
  L 0.894/0.845, R 0.837/0.817 (все четыре ниже 0.97). Критерий
  максимальной паузы шум действительно пропускает (max run 18/10 мс),
  но occupancy и margin его отсекают. False pass шум-онли по
  комбинированному кандидату — 0.
* margin ≥20 дБ один не разделяет gapped-случаи (True почти всюду),
  но отсекает noise-only.
* L/R: различий кандидатов нет (steady −72: margin 29.8/29.9 дБ).
* Базовый уход −23.5 ppm виден в production (−23.1 ppm L). ±100 ppm:
  −100 ppm → clock_ok=False (|ppm|>100 с учётом базового −23.5),
  +100 ppm → True — корректная асимметрия допуска.

* Реальный эффект утечки мал: максимум **≈0.35 ppm (L)** и
  **≈0.056 ppm (R)**; **L/R-сдвиги не идентичны** (L систематически
  больше R при одинаковом номинале).
* **Эффект длительности НЕ монотонен** по знаку эффекта: у 1000 Гц
  стресс −90 дБc медиана 2.07 → 2.86 ppm при 2 → 6 с (выросла); у
  997 Гц — 1.71 → 0.26 (упала); у 1013 Гц — 0.65 → 0.03 (упала).
* **1013 Гц материально избегает эффекта**: p90 0.071 ppm на 2 с и
  0.007 ppm на 6 с (у 1000 Гц: 0.304/0.324).
* **Все 544 строки line_contaminated** — это НЕ измерение детекции
  line-QC утечки 1000 Гц: флагается 60 Гц линия гребёнки (−16 дБc)
  и в AM-контролях боковые (±5/±20 Гц, −12 дБc). Вывод о детекции
  именно утечки из этих статусов не следует.
* **nearby_probe_hits = 0/544 не доказывает ничего об обнаружении
  утечки**: при пилоте 1000 Гц утечка отстоит на 0.0235 Гц (внутри
  исключённого ядра ±0.3 Гц); при 997/1013 Гц — вне зоны поиска
  ±1.5 Гц. Проба на фактическом смещении утечки не проверена.
* **AM/FM контроли (48)**: nearby-пробник ни разу не сработал —
  наивное «nearby-hit = reject» не отбраковало бы легитимную
  модуляцию. Но full-window line-QC флагает AM-боковые (−12 дБc) —
  «line-hit = reject» отбраковал бы АМ.

* Медиана |err|/CRLB 0.61–0.85, **но p90 = 1.29–1.77 и максимумы
  1.80–2.56** — оценку нельзя называть «близкой к CRLB» только по
  медиане: распределение имеет тяжёлый правый хвост.
* **L/R корреляция ошибок 0.92–0.97** во всех ячейках (коррелированный
  шум 0.95): независимость ошибок каналов предполагать нельзя,
  объединение L/R не даёт √2.
* **Исправленная причина заниженной estimator_sigma**: тест C использует
  **est_lsq отдельно для каждого канала, а не est_joint** — прежнее
  объяснение через 2×2 whitening неверно. Зафиксированный факт:
  отношение estimator_sigma / median CRLB — **1.007–1.032 на белом
  шуме и 0.260–0.273 на цветном** (занижает ≈ в 3.7–3.9 раза).
  Механизм расхождения этим тестом не установлен.
* статусы: ok 384/384 (60 Гц гребёнка в этот тест не включена).
