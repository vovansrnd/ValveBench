## A. Narrowband occupancy (34 case, 10/20 мс демод-кадры, L/R раздельно)

Production (Rig.run + clock_check): steady −66/−72 → pass; tail-гэпы
150/350/800 мс — reject на −66, но **pass на −72** (150/350/800!);
front 40/49% → pass; split-40% → reject; периодические гэпы 20 мс →
pass, 40–100 мс → reject; AM 0.2/0.5/0.5 → pass, AM 0.8/2 Гц → reject;
±100 ppm → pass (−100 ppm: clock_ok=False при |ppm|>100 — корректно);
noise-only → reject.

Кандидаты (combined: margin ≥10 дБ + occupancy ≥0.97 + max run ≤50 мс):
* отделяют continuous (steady/AM 0.2–0.5/±100 ppm → True) от gapped
  (tail ≥150 мс, split-40%, периодические ≥40 мс → False) и noise-only
  (False);
* **occupancy ≥0.97 строже production**: front-40/49% (production pass)
  кандидат отклоняет; периодические 20 мс гэпы (production pass,
  SNR норма) кандидат тоже отклоняет — ложные отказы кандидата на
  валидном непрерывном сигнале с 20 мс гэпами;
* **noise-only**: occupancy-компонента в кандидате = False (envelope
  q95 −100.6 дБFS против порога), margin ≥10/≥20 дБ = False
  (pilot/off-band margin 1.5 дБ L, −0.1 дБ R) — т.е. occupancy alone
  шум-онли бы пропустила (компонента run ≤50 мс у шума True), но
  margin-критерий отсекает; ложных pass по комбинированному
  кандидату — 0;
* L/R: различия кандидатов нет (29.8/29.9 дБ margin на steady −72);
  базовый уход −23.5 ppm виден в production ppm (−23.1/−23.4).
