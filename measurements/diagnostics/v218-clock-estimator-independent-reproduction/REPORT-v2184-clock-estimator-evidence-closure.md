## 1. «868 Гц»: ВОСПРОИЗВЕДЁН на правильной версии — механизм установлен

**Исправление ревизии v2.18.3**: агент воспроизводил легаси-версию
(0b6853b, центроидный старт), а 868 Гц был получен НЕЗАВИСИМЫМ
оценщиком из 8d8b040 (v2.18.1) с coarse-параболой БЕЗ ограничения
смещения и БЕЗ проверки кривизны. v2184_868_reproduction.py
воспроизводит ИМЕННО эту версию с точными seed
(218200+997000+300+tr, tr 0..99 — формула v2181_lsq_pilots.py).

**Результат: 868 Гц ВОСПРОИЗВЕДЁН на 100/100 прогонов. Механизм
полностью установлен** (per-trial логи в JSON):

1. coarse-argmax наци ГРАНИЦУ полосы поиска (бин 999 = 999.0 Гц —
   край ±2 Гц): утечка линии 1000 Гц (на 42 дБ громче пилота) растёт
   к границе → argmax на краю;
2. соседи ВОЗРАСТАЮТ (1.45 → 189.8 → 379.7) — «пик» является
   ВОЗРАСТАЮЩИМ склоном, парабола НЕВАЛИДНА (кривизна +1.42 > 0 —
   выпуклость вверх, минимум-условие нарушено);
3. смещение параболы (y0−y2)/(2·denom) = **−133 бина** (неограниченное!)
   → f0 = 865.985 Гц;
4. RSS-уточнение вокруг 866 → f_est = 865.83 Гц.

Следствие для production: coarse-поиск ОБЯЗАН проверять (а) кривизну
параболы (вогнутый пик) и (б) положение пика внутри полосы — оба
условия в v2184_estimators.py реализованы (status='edge_peak').

## 6. Расписание: ЧЕТЫРЕ компонента разделены (ревизия п.6)

Ревизия v2.18.3: «Нельзя называть все эти элементы одним и тем же pad».
Разделены: **НАЧАЛЬНЫЙ padding backend** (sleep 0.30, backend.py:574);
**КОНЕЧНЫЙ padding backend** (~0.05 с — латентность тракта/запуска D10,
компонента декомпозиции аудитора «0.30+0.05+1.5»); **хвостовой резерв
Rig._seg** (0.05, в КОНЦЕ сегмента); **settle 0.4** (внутри сегмента —
pre-окно анализа, тон играет сквозь него); **edge-lead 1.5**.

Расписание: НАЧАЛЬНЫЙ padding 0.30 + латентность 0.05 + lead 1.5 =
**1.85 с**; конец = 1.85 + 2.45 (settle 0.4 + блоки 2.0 + резерв 0.05 —
все ВНУТРИ тона) = **4.30 с**. Верификация кадрами программы: тон в
кадре 1.500 = lead ✓. Захват №1: голова **+375 мс**, хвост **0 мс**,
окно [2.650, 4.650] — вылет **+350 мс**; assertions PASS ✓.
Наблюдение о 375 мс сохранено БЕЗ физической причины (механизм —
отдельная работа).
