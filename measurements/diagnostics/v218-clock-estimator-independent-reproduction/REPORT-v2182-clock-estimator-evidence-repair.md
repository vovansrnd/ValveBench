## 2. σ_pred: вывод с множителем 2, per-trial покрытие

```
logL(f) = −RSS(f)/(2σ²) + const;  RSS'(f̂) = 0
RSS(f̂+δ) = RSS(f̂) + δ²·RSS''(f̂)/2
FI_obs = −logL''(f̂) = RSS''(f̂)/(2σ²)  →  var(f̂) = 2σ²/RSS''(f̂)
whitened (σ=1): var(f̂) = 2·step²/denom_profile
```
В v2.18 множитель 2 был пропущен (σ_pred занижена в √2: 0.16 против
0.23) — гипотеза координатора подтверждена выводом и MC. σ_pred
сохраняется отдельной структурой (не через stats() с PPM_TRUE);
покрытие считается **per-trial**: |err_i| ≤ σ_pred_i (таблицы выше).
Статус: **калибрована на верифицированных моделях; для реального
аппаратного шума — не заявляется** (текущий GLS учитывает только
нулевой межканальный временной сдвиг, не полную частотную структуру —
ограничение документировано).
