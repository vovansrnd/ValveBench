## П.2 — LSQ независимо от центроида: ПЕРЕДЕЛАНО

* **Грубая оценка независима**: пик оконной периодограммы с параболой в
  ±2 Гц (покрытие ±200 ppm — 2× запас к ±100 ppm); МНК-уточнение ±0.15 Гц
  (25 точек) + парабола. Центроид в LSQ НЕ участвует.
* **Покрытие ±100 ppm**: ppm_true ∈ {−100, −50, −23.5, 0, +50, +100} —
  ошибки ≤ 0.003 ppm (−30 dBFS SNR) ✓ полный захват диапазона.
* **Двойная децимация устранена**: v2.18 MC децимировал до 48 кГц, затем
  est_lsq децимировал ещё раз → фактически фит на 12 кГц. В v2.18.1:
  децимация однократная, **фактическая частота фита — 48 кГц**
  (документировано в est_lsq: децимация только при fs > 96 кГц).
* **Пилоты 997/1013 Гц против сетевых гармоник** (`v2181-lsq-pilots.json`):
  * **ИЗМЕРЕННЫЕ уровни гармоник тракта** (ансамбль 129 окон): линия
    1000 Гц = −106.8 дБ/Гц ≈ **−93 дБFS — на 21 дБ НИЖЕ пилота −72** →
    в реальном тракте пилот 1000 Гц в безопасности (как и 997/1013);
  * стресс-тест (гармоника ЛОЖИТСЯ НА ПИЛОТ, 12–42 дБ выше):
    пилот 1000 → bias +23.5 ppm (оценщик цепляется за гармонику —
    демонстрация риска аудитора ✓); LSQ на 997/1013 при таком гуме:
    смещения ±80–13000 ppm (Дирихле-боковые лепестки сильной линии
    смещают RSS-минимум); **центроид на 1013 при этом УСТОЙЧИВ
    (σ 0.36, bias 0 — окно ±3 бина защищает от 13-Гц-удалённой линии)** —
    контрпример к «центроид всегда хуже»: у центроида узкое окно,
    защищающее от далёких линий; у LSQ — уязвимость к сильным линиям.
* Production-частота не менялась.

## П.3 — расчёт неопределённости: ВЫВОД ПРОВЕДЁН, МНОЖИТЕЛЬ 2 ПОДТВЕРЖДЁН

Вывод (для whitened остатков σ = 1):
```
logL(f) = −RSS(f)/(2σ²) + const
FI_obs = −logL''(f̂) = RSS''(f̂)/(2σ²)
var(f̂) = 1/FI_obs = 2σ²/RSS''(f̂) = 2·step²/denom_profile
```
В v2.18 использовалось var = step²/denom — **множитель 2 пропущен** →
σ_pred занижена в √2. Числа совпадают с гипотезой координатора:
предсказание 0.16 против фактических 0.23; 0.23/0.16 = 1.44 ≈ √2 ✓.

**MC-верификация после поправки** (σ_pred vs фактическая σ jGLS):
pred/actual = 1.26–1.32 (σ_pred слегка завышена — согласуется с покрытием:
1σ-coverage 0.803–0.828 ≈ P(|z|≤1.3) = 0.806 для гауссианы ✓✓;
2σ-coverage 0.984–0.995 ✓). **σ_pred калибрована в пределах ~1.3×** —
соответствие расчётной неопределённости фактической ПОДТВЕРЖДЕНО
(остаточное 1.3× — оставшийся модельный зазор, документирован).
Отдельная структура sigma_pred_stats: mean/median, фактическая σ,
pred/actual, покрытие 1σ/2σ — на каждый уровень ✓; в stats() с
вычитанием PPM_TRUE не передаётся ✓ (в скрипте для интерпретации поля
JSON bias = mean σ_pred + 23.5 отмечено в комментарии).

## П.5 — квантование resampling: ПРОВЕРЕНО

* **Точный шаг**: Δppm = 1e6/N_padded = **0.947 / 0.801 / 0.694 ppm** для
  5/6/7 с (padded 1.056M/1.248M/1.44M) — подтверждает порядок 0.7–1 ppm.
* Численный замер фактического остатка: округлённый resample
  **−0.26…+0.20 ppm**; точная дробная коррекция (интерполяция по времени)
  **±0.01 ppm** — квантование устранимо полностью без production-патча.
* Фазовое влияние: ε=0.7 ppm → 10.1° на 20 кГц/2 с, 20.2° на 10 кГц/8 с;
  ε=1 ppm → 14.4°/28.8°. Для амплитудной H1 влияние малое; для фазы и
  групповой задержки на ВЧ — существенно. Дробная коррекция устраняет.
