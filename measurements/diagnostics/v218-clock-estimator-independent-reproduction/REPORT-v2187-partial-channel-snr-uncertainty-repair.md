## §1. Истинная изоляция каналов (п.1)

Замечание координатора подтверждено: в v2.18.6 `ok_partial` выбирал
старт из валидного канала, но включал ОБА канала в ковариацию,
whitening и совместный RSS — загрязнённый канал участвовал в оценке.

`est_joint()` v2.18.7 возвращает СЛОВАРЬ
`{f_est, variance_hz2, sigma_hz, status, channels_used, qc_L, qc_R, fs}`:

* оба канала `ok` → совместный GLS по обоим (как в v2.18.6), статус
  `ok`/`grid_edge`, channels_used = ['L','R'];
* валиден один → результат ТОЛЬКО этого канала: f_est и variance_hz2
  **побитово совпадают** с его `est_lsq` (та же ветка вычисления —
  допуск 0); загрязнённый канал не участвует ни в чём; статус
  `ok_partial`;
* оба невалидны → отказ (f_est/sigma_hz = None, статус — причина).

Юнит-тесты: L чист / R помеха +3 Гц → `ok_partial`, channels_used
['L'], f_est ≡ est_lsq(L) точно; зеркально R чист / L −3 Гц; помехи
−20/−30/−40 дБFS с разными фазами — совпадение точное во всех; оба
загрязнены → отказ `line_contaminated`, channels_used = [].

## §2. Tone-presence gate (п.2)

Замечание подтверждено: `snr_local_db` в v2.18.6 был информационным;
контрольная проверка координатора (200 записей шума −80 дБFS без
пилота) давала `ok` в 55/200.

Гейт в `est_lsq` — carrier-local SNR, выровнен с production
(`measure.py:26 CLOCK_MIN_SNR_DB = 20.0`, та же конструкция «мощность
несущей против локального пола»): после фита спектр остатка Wr, пол
= медиана |Wr|² в полосе ±32 Гц вокруг f_est (исключая ±2 Гц),
эквивалентный rms шума в полосе = sqrt(пол·K·2/(n·Σw²)), SNR =
20·log10(amp/rms). Пороги:

* `snr < 0 дБ` → **tone_missing** (амплитуда фита статистически
  неотличима от проекции шума; измеренный диапазон шума без пилота:
  −32.8…−6.7 дБ);
* `0 ≤ snr < 20 дБ` → **snr_low** (тон есть, но слаб;
  = CLOCK_MIN_SNR_DB);
* `≥ 20 дБ` → line-QC (v2.18.6 без изменений).

Результаты тестовых классов (`v2187_unit_tests.py`, 32 PASS):

| Класс | Результат |
|---|---|
| шум −80 дБFS без пилота, 200 записей | **ok = 0** (v2.18.6: 55) — tone_missing |
| белый шум −96 без пилота, 100 | ok = 0 |
| НЧ-тяжёлый шум без пилота | tone_missing |
| обрыв тона в середине окна | snr_low (18.7 дБ) |
| тон только в последней четверти | snr_low (18.8 дБ) |
| частично заполненное окно (40%) | snr_low (17.6 дБ) |
| пилот −110 дБFS при шуме −96 | snr_low (17.4 дБ) |
| жёсткий клиппинг | line_contaminated (гармоника 3f₀, −11 дБc) |
| чистый синус / белый −72 / цветной −72 с пилотом | ok |

Ни один класс без полезного тона не получает `ok`; отказные статусы
сохраняют f_est как информационную «сырую» оценку. Отмечу: пограничный
пилот −100 дБFS (carrier-local +27 дБ — тон есть и измерим благодаря
2-с когерентному усилению) отказывается line-QC по линиям остатка —
не по SNR; поведение зафиксировано тестом.

## §3. Неопределённость: один sqrt (п.3)

Замечание подтверждено: v2.18.6 MC считал `sqrt(2·var_f)` — лишний √2
поверх var = 2/RSS''. Деривация зафиксирована в докстринге: профильная
правдоподобность даёт var(f̂) = 2σ²/RSS''; для joint RSS вычисляется на
whitened-данных, где whitening нормирует остаточную ковариацию 2×2 к
единичной — σ'² = 1 точно, поэтому variance_hz2 = 2·step²/denom; для
одиночного канала σ² = mean(resid²) входит явно: variance_hz2 =
2·mean(resid²)·step²/denom. `sigma_hz = sqrt(variance_hz2)` —
преобразование ровно одно. Ожидаемый эффект: pred_over_actual white
1.462 → ≈1.03 (√2·погрешность конечной разности кривизны), colored
0.511 → ≈0.36 — подтверждено пересчётом MC (§6).

## §4. Точный replay −127 ppm (п.4)

Точная функция est_lsq из v2184_estimators.py (HEAD 4fc938e, bounded-
coarse, баг curv > 0, guard, RSS ±0.15 Гц) — НЕ 8d8b040.

Конструкция восстановлена систематическим поиском отпечатка
(f_est = 996.85 = нижний край сетки): **Fs 192 кГц, длительность 2 с
(N = 384000), штатная децимация resample_poly(1, 4) → 48 кГц внутри
est_lsq; пилот 997·(1−23.5e-6) −60 дБFS (фаза phase0-формулы v2.18.1);
линия 1000·(1−23.5e-6) −30 дБFS (фаза 2π·rng.random()); шум −96 дБFS;
seed = 218200+997000+300+tr**.

Результат (100/100): статус `ok` ВСЕГДА; **48/100 ровно −127.0 ppm**
(аргмин = нижний край 996.85), **52/100 ровно +174.0 ppm** (верхний
край 997.15); coarse-пик 997.0 во всех; направление задаётся фазой
линии. Историческая ошибка принималась молча. v2.18.7 на тех же
сигналах: line_contaminated **100/100** с атрибуцией линии.

Реконструкция задокументирована с негативными результатами:
при пилоте −72 дБFS coarse уходит на край полосы (утечка линии в бин
998.5, первый боковик Ханна −31.5 дБ) — семья edge_peak, не −127;
вариант 1 с @ 192 кГц даёт edge_peak 100/100 (главный лепесток Ханна
T=1 с накрывает бин 999); уровень −60 и длительность 2 с —
единственная найденная конструкция, воспроизводящая −127.0 точно.
Семья 8d8b040 (+1775.7 ppm) сохранена отдельно
(`v2186-legacy-counterexample.json`), не помечена как −127 replay.

## §5. Sweep line-QC: +20…−45 дБc × ±1…±5 Гц (п.5)

3090 прогонов (позитивы 2730 = 9 уровней × 10 смещений × 30 + реальные
профили 30; негативы 360). Полная сетка с размерами выборки —
`tables/confusion.md`, per-trial в `v2187-qc-sweep.json`.

**Негативы — FP = 0 всюду**: с пилотом (чистый синус, белый −72,
цветной −72) 180/180 TN; **без пилота** (−80/−96/НЧ-тяжёлый)
180/180 корректно отказаны (tone_missing/snr_low), ложных принятий
**0/180** — гейт п.2 работает и в sweep.

**Позитивы**: TP 1303, из них атрибуция line_hz в ±1.5 Гц от помехи —
**1303 (100%)**; TP_unnamed 48 (отказы grid_edge); FN 1379 — честная
структура (по ячейкам):

| Зона FN | Принято | |err| сдвиг от истинного пилота |
|---|---|---|
| **Слепая зона ±1/±1.5 Гц** — помехи исключаются QC по построению | 713 | +10 дБc: до **118 ppm**; 0 дБc: до 56; −10: до 14; −20: до 5.4; ≤−30: ≤1.4 |
| **Слепая зона ±2 Гц** (частично: бин рядом) | 238 | 0 дБc: 13–31; ≤−10: ≤30; ≤−20: ≤30... фактически ≤5 при ≤−20 |
| **Порог −35 дБc, |off| ≥ 2 Гц** — разброс измеренного dbc ±0.5–1 дБ пересекает порог | 48 | ≤0.7 ppm |
| **Подпороговые −40/−45 дБc** (все смещения ≥ 2 Гц) | 300 | **≤0.5 ppm** — влияние ничтожно |

Выводы: (а) вне слепой зоны при |дБc| ≥ 30 (линия громче) QC
детектирует ~100% с точной атрибуцией; (б) у порога −35 — частичное
детектирование, соответствует точности измерения dbc; (в) подпороговые
линии дают пренебрежимый сдвиг ≤0.5 ppm — accept корректен; (г)
**слепая зона ±1.5 Гц — главный честный предел архитектуры**: помеха
±1 Гц на 0 дБc (равна несущей) даёт bias 48–56 ppm, на +10 дБc — до
118 ppm, и QC её не видит (она внутри структурной утечки фита).
Расширение детектирования внутрь зоны — отдельная архитектурная
работа (§10).

Реальные профили (22 линии из WAV, амплитуды/фазы): 30/30 отказаны,
атрибуция к ближайшей внесённой линии 30/30.

## §10. На решение координатора

1. **Порог гейта**: snr_min = 20 дБ = production CLOCK_MIN_SNR_DB;
   эмпирическое разделение классов wide (шум без пилота ≤ −6.7 дБ,
   обрывы/частичные окна 17.6–18.8 дБ, полноценный сигнал ≥ 24 дБ на
   реальном профиле). Требует ли production иного порога — решение
   координатора; порог — один параметр QC_CFG.
2. **Слепая зона ±1.5 Гц**: помехи внутри зоны исключаются QC по
   построению (структурная утечка фита); их влияние видно в sweep
   (§5). Расширение зоны детектирования внутрь ±1.5 Гц потребует
   иного механизма (например, сравнение амплитуды фита с локальным
   полом) — отдельно.
3. **σ_pred на цветном** — по-прежнему занижена (см. §7); spectral
   whitening — отдельная архитектурная работа.
4. Production-перенос — после утверждения; производство не тронуто.

## §11. Ограничения

* Нулевые ошибки на тестовых выборках не означают нулевую частоту
  ошибок в реальном тракте (размеры выборок указаны по ячейкам).
* Валидация извлечения мощности линий: |err| ср 1.21 дБ на слабых
  линиях (−110…−118 дБFS) — прежняя оговорка сохраняется.
* Реконструкция конструкции −127 ppm: уровень пилота −60 дБFS и
  длительность 2 с подобраны поиском отпечатка; исторический скрипт
  не был закоммичен, точное соответствие подтверждено воспроизведением
  значения −127.0 с точностью 0.05 ppm и механикой (coarse 997.0,
  аргмин на краю).
