# v2.25.0 — agent blocked-inventory report

## Итог: BLOCKED — захват не выполнен, требуется подтверждение подключения

Контракт требует записать 384 с реального шума с уже подключенного
«known quiet analog measurement path» нативно (96 кГц, стерео, без
resampling). Инвентаризация на vovans-PC выявила единственное
capture-устройство (E-MU 0404 USB, hw:CARD=USB,DEV=0 — native
S24_3LE, 2/4 канала, 96 кГц поддерживается, устройство свободно),
но **текущее состояние аналогового входа не удовлетворяет условию
«known quiet»**, поэтому по контракту остановка после инвентаризации.

## Наблюдения (10-с пробный захват, read-only, устройство не менялось)

| Параметр | L | R |
|---|---|---|
| RMS | −71.0 дБFS | −69.9 дБFS |
| Peak | −47.5 дБFS | −46.2 дБFS |
| Клиппинг | 0 | 0 |

* Полная полоса: block RMS (0.5 с) −84.9…−58.3 дБFS, разброс
  **26.7 дБ** — сигнал нестационарен.
* Спектр: максимум PSD на **~12 Гц** — сильная НЧ-составляющая;
  выше 300 Гц пол тихий: block RMS −85.0…−80.7 (разброс 4.3 дБ),
  медианная PSD ~−130 дБ/Гц.
* DC-смещение малo (+3.6e-05 / +4.2e-05).

## Причина остановки

1. **Физическое подключение входов E-MU неизвестно агенту** —
   подключалось пользователем ранее (v2.18.6); контракт запрещает
   догадываться о DUT/источнике.
2. **Вход не является «quiet» в полной полосе**: НЧ-составляющая ~12 Гц
   даёт блоки до −58 дБFS. Является ли она ожидаемой частью
   измерительного пути (например, idle-шум подключенного D10) —
   может знать только пользователь/координатор.
3. Замечание для решения: НЧ-составляющая (12 Гц) лежит вне всех полос
   анализа (пилот 1 кГц ±32 Гц; residual-PSD 2–32 Гц от несущей;
   отбрасывается DC-членом фита) — если пользователь подтвердит, что
   подключение и есть ожидаемый тихий путь, повторный прогон возможен
   без каких-либо изменений оборудования. Решение — не за агентом.
