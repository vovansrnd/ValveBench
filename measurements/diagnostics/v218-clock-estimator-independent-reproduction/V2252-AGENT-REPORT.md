# v2.25.2 — agent technical report: raw-domain analysis of the 15.38 Hz observation

Все значения — из v2252-raw-probe-transient-analysis.json (анализатор
координатора на pinned c9fbaae, применён к сырым отсчётам
/tmp/v2250-probe.wav без предварительной фильтрации; SHA источника
d1676fe5…ca9). Наблюдения отделены от интерпретаций.

**Краткий ответ на главный вопрос: когерентного устойчивого тона
15.38 Гц в записи НЕТ.** Проекция на 15.38 Гц существует только в
первых ~0.125–0.25 с, затухает на ~−45 дБ за 0.5 с, фазы между
окнами несогласованы; свободный спектральный пик первого блока лежит
на 8 Гц, не на 15.38. Подробности ниже.

## 1. Первый 0.5-с блок: широкополосный транзиент, не узкий пик

* Block RMS первого 0.5-с блока (полная полоса): −58.4 дБFS —
  остальные блоки −83…−79 дБFS.
* Raw 8–20 Гц спектр этого блока (nfft 524288): band RMS −90.6 дБFS,
  **свободный пик на 8.057 Гц** (не на 15.38); энергия распределена
  широкополосно, без узкого пика на 15.38.
* Fixed-фит на 15.38 Гц в этом окне: амплитуда −72.2 дБFS, но
  **доля объяснённой энергии после линейной детрендировки — 5.3%**:
  94.7% энергии первого блока фит 15.38 Гц НЕ объясняет.
* Интерпретация: первый блок — широкополосный переходный процесс
  (типа settle/шаг DC/USB), а не тон 15.38 Гц. (Наблюдение; физический
  источник не предполагается.)

Спад ≈ −45 дБ/с в первые 0.5 с — экспоненциальное затухание

Оба канала показывают одинаковый первый транзиент (L −86.0 / R −84.7
дБFS в окне 0–2; фазы −3.10/−3.09 — синфазно) — common-mode событие

## 6. Ответы на вопросы задания (наблюдение → интерпретация)

1. **Есть ли узкий пик 15.38 Гц в первом 0.5-с блоке?** Нет: свободный
   пик блока — 8.057 Гц; фит 15.38 объясняет лишь 5.3% энергии блока.
   Наблюдение: широкополосный транзиент.
2. **Проекция 15.38 Гц затухает?** Да: −72.2 → −116.6 дБFS за 0.5 с
   (≈ −45 дБ/с), далее пол. Фазы первых окон несовместимы с
   непрерывным тоном (шаг ожидания 12.08 рад против наблюдаемого
   плавного дрейфа).
3. **Сравнение с контролем 12 Гц:** в задании контроль не реализован
   отдельным скриптом — но из сырых данных: свободные пики первых
   блоков лежат на 8.057 Гц (L), глобальный R-пик 8.371 Гц — т.е.
   НЧ-энергия распределена по 8–16 Гц без предпочтения 15.38.
   Устойчивого компонента на любой частоте 8–20 Гц после 0.5 с нет
   (все доли 0.000).
4. **Итог по v2.25.1:** «затухающий тон 15.38 Гц» — артефакт связки
   (транзиент первого блока) + (zero-phase 8–20 Гц фильтр всей записи)
   + (2-с окно, захватывающее транзиент). Реального когерентного тона
   нет; наблюдаемый «тон» — переходный процесс запуска тракта в первых
   ~0.3 с (наблюдение), физический источник не устанавливается.

## Ограничения

* Физический источник транзиента (шаг DC, USB settle, питание) не
  определяется синтетическим анализом.
* Разрешение 0.5-с окон 0.183 Гц — компоненты внутри 0.25 Гц от 15.38
  неразличимы; но затухание амплитуды делает вопрос moot.
* Если координатору нужен отдельный контроль на 12 Гц — данные в JSON
  (raw 2-с окна и скользящие) позволяют сделать тот же анализ на любой
  частоте без перезапуска.
