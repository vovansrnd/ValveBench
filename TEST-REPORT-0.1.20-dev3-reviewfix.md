## Ограничения проверки

- GTK4 не запускался в данной среде: Python-модуль `gi` отсутствует. Структура/логика страниц тестировались под заглушкой; визуальная приёмка остаётся агенту.
- Физические E-MU и ASUS не запускались и не измерялись.
- Glitch streaming memory test пройден на записях 30 и 90 секунд (83 и 84 МиБ peak по тестовому измерителю). Реальный 10-минутный аппаратный прогон не выполнялся. Хранение 1-мс огибающей масштабируется с длительностью; оценка около 20 МиБ на 10 минут для двух ведомых каналов — расчёт по размеру массивов, не результат 10-минутного замера.
- Отдельный процесс `AnalysisWorker` проверен минимальным синтетическим smoke; реальный GTK lifecycle/частота обновления на рабочем столе не проверялись.
- Коррекция Peak Hold всё ещё опирается на существующий профиль петли ЦАП→АЦП. Страница показывает предупреждение, что профиль включает вклад ЦАП; чистого ADC-only профиля в проекте пока нет.
- Полная проверка `frame_integrity` для каждого кадра свипа Peak Hold не включена: для этой страницы остаётся фильтрация событий потока и тоновый tracking. Синтетические тесты одиночных выбросов прошли, реальные записи нужны для оценки порогов.
