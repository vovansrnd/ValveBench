# ValveBench 0.1.15 — интерфейс измерений и графиков

## Состояние измерения

На измерительных страницах над графиком находится постоянная строка состояния:

- **ГОТОВО К ИЗМЕРЕНИЮ** — действие ещё не запускалось.
- **ИЗМЕРЕНИЕ ВЫПОЛНЯЕТСЯ** — запущена фоновая задача, индикатор вращается, кнопки этой страницы временно недоступны.
- **ИЗМЕРЕНИЕ ЗАВЕРШЕНО · N с** — задача завершилась; результат находится в отчёте под графиком.
- **ИЗМЕРЕНИЕ НЕ ВЫПОЛНЕНО** — возникла ошибка открытия карты, измерения или обработки результата; причина показана в отчёте.

Строка состояния не очищается автоматически. В заголовке окна также сохраняется короткий статус и время выполнения.

## Масштаб графиков

Под каждым графиком измерительной страницы расположены два поля `Масштаб Y: от / до`, кнопка **Применить** и кнопка **Авто**.

1. Измени нижнюю и верхнюю границы вертикальной шкалы.
2. Нажми **Применить**.
3. Для возврата к автоматическому диапазону нажми **Авто**.

Ручной диапазон сохраняется при поступлении новых измерительных данных. При переключении графика на другую физическую величину (например, дБ → градусы фазы или когерентность) ручной диапазон снимается, чтобы не обрезать данные в новых единицах.

Большой экран **Спектр** имеет отдельные селекторы нижней/верхней границы dBFS и выбор частотной полосы.

## АЧХ фонокорректора

Стандартная RIAA выбрана как целевая характеристика обычного фонокорректора. В режиме inverse-RIAA тестовый свип предварительно корректируется, чтобы на входе проверяемого корректора получить нужную форму сигнала; результат `Отклонение от RIAA` показывает ошибку относительно идеальной характеристики, где 0 дБ — норма.

Исходный вертикальный масштаб этого графика — **−0,5…+0,5 дБ**. На графике есть пунктирная нулевая линия. Деления автоматически подбираются примерно по 0,1 дБ. Для более широкого диапазона можно вручную изменить границы или нажать **Авто**.

`АЧХ (норм. на 1 кГц)` по умолчанию показывает ±2 дБ. Переключение видов сбрасывает ручной диапазон, поскольку у THD, процентов и фазы другие единицы.

Для нестандартной НЧ-коррекции можно выбрать `RIAA + IEC`; для обычного фонокорректора оставляй `RIAA`.
