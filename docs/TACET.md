# TACET Vinyl: Check — что можно измерить программно

Ниже сохранена структура дорожек из предоставленного владельцем текста. ValveBench не предполагает, что все сигналы этой пластинки являются калиброванными лабораторными тонами.

| Дорожка | Сигнал по описанию | Что можно делать в ValveBench | Ограничение |
|---|---|---|---|
| A1 Tracking ability | Ударные, колокольчики, фортепиано, бас-барабан, синус поверх бас-барабана | Записать и слушать; исследовать спектр/искажения выбранного фрагмента | В основном тест на слух и способность считывания. Нельзя превращать его в универсальный численный коэффициент без точной разметки/эталона дорожки |
| A2 Wow and flutter | Синус 3150 Hz | Отслеживать мгновенную частоту, среднее, σ и peak deviation | Текущий показатель необвешенный. В тексте отдельно сказано, что отверстие/эксцентриситет диска и допуски записи тоже вносят отклонения; для стандартизованной оценки требуется weighting и эталон скорости |
| A3 Phase | Чередование mono и mono out-of-phase pink noise | Широкополосные RMS L/R, нулевая корреляция, круговое среднее фазы cross-spectrum в когерентных частотных точках | Для mono ожидаются корреляция около +1 и фаза около 0°; для out-of-phase — около −1 и ±180°. Результат включает всю стереоцепь, а не только картридж |
| A4 Crosstalk | 1 kHz по очереди только L и только R | Снять два фрагмента и сравнить активный/неактивный канал | Измерение включает головку, проводку тонарма, кабель, вход фонокорректора и ADC. Для измерения самого фонокорректора лучше отдельный электрический тест |
| A5 Tracking angle error | 341 + 659 Hz, затем 1 kHz mono и out-of-phase | Измерить продукт 1000 Hz при двух исходных тонах; отдельно анализировать баланс/фазу 1 kHz | Продукт 1000 Hz — индикатор эффекта, не прямое измерение угла VTA. На него влияют нелинейность картриджа и всей цепи |
| A6 Skating | 300 Hz с возрастающим уровнем, 41 s | По скользящим окнам построить уровень и THD L/R; сравнить момент и симметрию срыва | Это не измерение силы skating в граммах и не универсальная настройка антискейтинга |
| A7 Pick-up arm resonance | 1000 + 1125 Hz, низкий тон от 5 до 15 Hz шагом 1 Hz | Просмотреть низкочастотную составляющую/спектр 5–15 Hz | Звуковая карта должна пропускать инфранизкую полосу. Внутренний high-pass интерфейса может скрыть пик; также видны шумы вращения и эксцентриситет |
| B1/B4 Sibilants and fricatives | Записи шипящих звуков в начале и конце стороны | Сравнить на слух, записать спектр и короткие фрагменты | В первую очередь слуховая проверка иглы/геометрии/внутренних дорожек; точный универсальный метрический критерий не задан |
| B2 Frequency response | Дискретные синусы 20 Hz–20 kHz; серия с RIAA cutting curve и повтор без неё | Автоматически распознавать устойчивые частотные ступени из WAV, измерять RMS L/R, нормировать на первую ступень 1 kHz и строить относительную кривую | В тексте нет точной длительности/амплитуд каждой ступени и заводской таблицы допусков. Для чистого сравнения RIAA/flat выделяйте соответствующий временной участок параметрами start/duration; результат включает картридж, фонокорректор и ADC |
| B3 Dynamics | 1 kHz и pink noise, ступени от −90 до −30 dB с шагом 6 dB | Сравнить порог слышимости с измеренным шумовым полом, если фрагменты размечены | Субъективная слышимость зависит от громкости, акустики, фонового шума и слуха; это не чистая характеристика одного фонокорректора |

## Команды WAV-анализа

Записать внешнюю дорожку с аналоговых входов (выберите устройство/частоту):

```bash
./run.sh cli --dev hw:1,0 --rate 96000 record --seconds 45 --wav ~/TACET-A6.wav
```

Анализ дорожки A2, если в WAV записан именно участок 3150 Hz:

```bash
./run.sh cli vinyl --file ~/TACET-A2.wav --test 3150
```

Анализ A3:

```bash
./run.sh cli vinyl --file ~/TACET-A3-mono.wav --test phase
```

Анализ A4, если выбран участок только L (повторите для участка только R):

```bash
./run.sh cli vinyl --file ~/TACET-A4.wav --test xtalk-L --start 0 --duration 10
./run.sh cli vinyl --file ~/TACET-A4.wav --test xtalk-R --start 10 --duration 10
```

Времена здесь примерные: укажите фактические интервалы по вашей записи.

Анализ A5:

```bash
./run.sh cli vinyl --file ~/TACET-A5.wav --test sum
```

Анализ всей 41-секундной дорожки A6:

```bash
./run.sh cli vinyl --file ~/TACET-A6.wav --test skating
```

Анализ низкочастотного спектра A7:

```bash
./run.sh cli vinyl --file ~/TACET-A7.wav --test resonance
```

Анализ B2 (частотные ступени автоматически распознаются из выбранного временного участка):

```bash
./run.sh cli vinyl --file ~/TACET-B2.wav --test response
# например, только участок первой серии:
./run.sh cli vinyl --file ~/TACET-side-B.wav --test response --start 120 --duration 180
```

Окно анализа по умолчанию — 1 с, шаг — 0,25 с. Если на пластинке каждая частота держится меньше секунды, результат может пропускать короткие ступени; это диагностический трекер, не анализатор с известной амплитудной калибровкой тестовой записи.

Параметры `--start` и `--duration` позволяют выбрать участок внутри длинной записи, например:

```bash
./run.sh cli vinyl --file ~/TACET-side-A.wav --test 3150 --start 32 --duration 20
```

Для A3 нужно записывать стерео и анализировать один устойчивый моно- или противофазный фрагмент розового шума. Анализ широкополосный: программа не трактует случайную фазу одного FFT-бина как фазу всего шумового сигнала. Для A5 используйте только устойчивую часть 341+659 Hz, исключая переключения и начало/конец дорожки.
