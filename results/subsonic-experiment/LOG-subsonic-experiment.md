# Протокол: субсоник-фильтр на лампового фонокорректора (A/B с ValveBench)

Дата: 2026-11-21. Оператор: vovans. Измерения выполнял агент ZCode по командам оператора.
Назначение документа: полная фиксация шагов, настроек, артефактов и выводов для передачи
автору скрипта проверки (tools/analyze_subsonic_filter.py) и для дополнительного анализа.

## 1. Цель

Клиентский фонокорректор (выход — SRPP на 6Н28Б: 680 Ом в обоих катодах, 470 мкФ в нижнем
катоде; далее выходной конденсатор 2,2 мкФ и резистор ~100 кОм в землю) подключён к
предусилителю с входом 10 кОм. На кривых пластинках ходят дифузоры. Решение: не нагружать
выход резистором, а добавить последовательно плёночный конденсатор (первый кандидат 2,2 мкФ),
позже — переключатель номиналов. Нужно измерить фактическую АЧХ и эффект добавленной ёмкости
под реальной нагрузкой, чтобы решить, достаточно ли фильтра первого порядка.

## 3. Команда измерения (одинакова для всех DUT-захватов)

```bash
./run.sh cli --rate 96000 noise-response --kind riaa --seconds 60 --level -36 --lo 2 --hi 1000 \
  --csv measurements/subsonic/<имя>.csv
```

`--iec` не используется. Бин Уэлча 0,732 Гц; первый бин 2,197 Гц. Профиль FR-калибровки карты
CLI не применяется (см. пункт «Замечания автору» A2) — для A/B-дельт это некритично.

## 5. Выводы измерений (по состоянию до установки дополнительного конденсатора)

- **F1. Входной импеданс гнезда E-MU высокий, а не 4–5 кОм.** При прямом включении корректора
  (2,2 мкФ → 100к → гнездо) на 20 Гц +0,1 дБ; при нагрузке 4 кОм ожидался срез ~19 Гц (−3 дБ @ 19).
  Оценка из захвата с шунтом 10к: эквивалентная нагрузка L = 8,0 кОм при 100к∥10к = 9,1 кОм,
  что даёт Z_гнезда ≈ 50–70 кОм (или выше при меньшем платном резисторе — номинал известен
  оператору как «порядка 100к, может чуть меньше»). Замечание из MEASUREMENT-CALIBRATION.md
  об оценке 4–5 кОм противоречит этим данным: наблюдаемый спад 3–4 Гц — собственный полюс
  тракта карты (есть и в петле, и в DUT-захвате), а не нагрузка гнезда.
- **F2. У карты есть собственный НЧ-полюс ≈3,5 Гц** (петля: fc 3,5 Гц при coh 1,0; с буфером 3,8;
  напрямую 2,7). Общий для всех захватов → в A/B-дельте сокращается.
- **F3. Корректор RIAA-точен**: 15–300 Гц ±0,2–0,3 дБ в обоих включениях; каналы совпадают
  лучше 0,2 дБ выше 25 Гц.
- **F4. «Клиентская» нагрузка 10к** даёт fc≈9 Гц (первый порядок, RMS подгонки 0,23 дБ).
  Эффект относительно высокоомной нагрузки: −4,8 дБ @ 8 Гц, −2,6 @ 10, −0,9 @ 15–20.
  То есть сам по себе он кривые пластинок почти не лечит: 4–8 Гц проходит с малым ослаблением,
  а ниже 4 Гц данные тонут в собственном НЧ-шуме корректора (coherence 0,3–0,5).
- **F5. Повторяемость метода** (петля→анализатор): ±0,01 дБ. Различия 0,5 дБ уверенно
  различимы; лимит точности — не метод, а НЧ-шум/фон корректора.
- **F6. Фон сети**: напрямую 50 Гц до +11 дБ (L); с буфером −0,8 дБ; с шунтом 10к +2,6 дБ (L).
  Буфер/гальваническая развязка разрывали земляную петлю. В анализ полоса 48–52 Гц
  исключается по coherence.
- **F7. НЧ (< 8 Гц) во всех DUT-захватах шумовой**: inverse-RIAA сигнал там на ~19 дБ тише,
  ламповый шум доминирует, coherence 0,1–0,5. Ослабление фильтра на этих частотах надо
  оценивать по дельте двух захватов при одинаковом шуме и гейту coherence ≥0,8.
- **F8. Δ петли −5,35 дБ** — равномерное усиление петли ЦАП→АЦП, частотно-независимо
  (после нормализации на 1 кГц петля плоская ±0,17 дБ на 20 Гц–20 кГц).

## 6. Ожидание для следующего шага (2,2 мкФ последовательно в L, нагрузка 10к)

Двухполюсная модель (C1=2,2 мкФ → узел 100к → C2=2,2 мкФ → 10к), дельта FILTERED−BYPASS:
−4,5 дБ @ 5 Гц; −2,9 @ 10; −1,9 @ 15; −1,3 @ 20; −0,7 @ 30. Асимптотический угол
1/(2π·10к·1,1мк) ≈ 14,5 Гц; нижний полюс ~1/(2π·100к·4,4мк) ≈ 0,36 Гц.
Сравнение формы дельты с этой моделью покажет, достаточно ли первого порядка.

## 7. Замечания автору (собранные по ходу)

- **A1. Семантика `*_RIAA_dev_db` в `noise-response --kind riaa`:** dev = fr_norm − riaa_playback(f).
  Для заведомо плоской петли dev(f) = −riaa_playback(f) (подтверждено: петлевой захват даёт
  −19,7 дБ @ 20 Гц, −13,1 @ 100, −5,3 @ 300 — точно кривая −RIA A playback). Для абсолютного
  чтения CSV нужно добавлять riaa_playback(f); в A/B-дельтах сокращается. Стоит задокументировать
  в SUBSONIC-FILTER-AB.md, чтобы не читали кривую петли как «провал корректора».
- **A2. CLI не применяет frequency_response_profiles.** Профиль передаёт только GUI
  (ui.py:3152 `response_calibration=profile`), cli.py:549 вызывает noise_response без него.
  Результат: из CLI кривые всегда некорректированы, при этом профиль сохранён и
  auto_apply_response=true. Предложение: автоматически резолвить профиль в CLI-хендлере.
- **A3. Инструкция/таблица ожиданий:** таблица «ожидаемого подавления» в задании к скрипту —
  это абсолютная АЧХ сети с фильтром, а анализатор печатает дельту FILTERED−BYPASS.
  При bypass-угле ~0,8–1 Гц (высокоомная нагрузка) дельта заметно меньше абсолютных цифр
  (напр. @ 5 Гц: −4,5 против −10). Нужна явная оговорка, чтобы не получить «фильтр не работает».
- **A4. MEASUREMENT-CALIBRATION.md, оценка входного импеданса E-MU 4–5 кОм** — опровергнута
  прямым измерением (см. F1); обновить раздел.
- **A5. `gainmatch.mixer_fingerprint_from_hw` возвращает None при одновременных потоках:**
  `amixer -c N contents` с timeout 3 c может не успеть во время play+record на USB — headless
  калибровка падала с «микшер изменился». Лечится повторами чтения (в tools/calibrate_pair_headless.py
  6 попыток × 0,5 с). Возможно, стоит поднять таймаут или повторить внутри библиотеки.
- **A6. У `Rig` нет метода close()** — внешний код вынужден полагаться на завершение процесса.
- **A7. Анализатор validated end-to-end на синтетике** (двухполюсная модель восстановлена
  с точностью 0,01 дБ; гейт coherence работает; скрипты проверки:
  `/opt/MyApps/Adudio/for_z/subsonic-lab/topology_check.py`, `synth_analyzer_test.py`).

## 11. Замена выходного конденсатора 2,2 → 1,0 мкФ (решение оператора)

Схема: выходной C = 1,0 мкФ в обоих каналах, резистор после конденсатора 120к,
L — дополнительно шунт 10к, R — только 120к. Захват `out1u-L10k_R120k.csv`
(та же команда, 60 с, −36 dBFS, 2–1000 Гц).

| Гц | L (120к+10к) | R (120к) |
|---|---|---|
| 5 | −11,0 | −3,5 |
| 10 | −4,2 | −0,5 |
| 15 | −2,5 | −0,3 |
| 20 | −1,3 | −0,0 |
| 40 | −0,5 | −0,5 |

Подгонка однополюсной модели (5–100 Гц, coh≥0,6): **L fc ≈ 12,2 Гц (RMS 0,20)**,
**R fc ≈ 3,6 Гц (RMS 0,20)**.

Расхождение: R совпадает с предсказанием (120к∥гнездо≈40к → ~4 Гц), L — нет:
ожидалось ~20 Гц (120∥10∥60 = 8,0к), измерено 12,2 Гц → эффективная нагрузка 13,0к.
Две гипотезы: (а) реальный Rout SRPP ≈ 5 кОм (тогда предыдущая сессия не сходится),
(б) ветвь шунта 10к сейчас имеет добавочное последовательное сопротивление ~8к
(точка пайки/номинал). Решающий тест — переставить шунт на R и повторить захват.

### 11.1. Своп-тест шунта (out1u-swap_R10k.csv)

L = 120к, R = 120к+10к. Подгонка (5–100 Гц, coh≥0.6): L fc ≈ 4,1 Гц, R fc ≈ 10,7 Гц.

Кросс-проверка свопом каналов: позиция «120к» 3,6 (R раньше) / 4,1 (L сейчас) Гц —
сходится; позиция «+10к» 12,2 (L раньше) / 10,7 (R сейчас) Гц — сходится в пределах
шума НЧ-подгонки. Эффект шунта воспроизводим на обоих каналах.

Из двух позиций текущей сессии (C≈1,0 мкФ подтверждён τ-подгонкой): Rout ≈ 5,4–5,8 кОм,
Z_гнезда ≈ 52–58 кОм. Вывод: выходной импеданс SRPP ~5–6 кОм — реальный, поэтому шунт
10к даёт угол ~11–12 Гц, а не ~20 Гц по чистой параллели. Эмпирическая карта
«нагрузка → угол» строится захватами каждой позиции, без опоры на модель.

### 11.2. Уточнение по ревью координатора (handoff/subsonic-experiment-context)

Дифференциальная подгонка разности каналов (общий полюс карты сокращается):
№1 fc = 10,70 Гц (coh≥0,50) / 10,72 (≥0,70); №2 fc = 9,79 / 10,03 Гц. RMS 0,14–0,20 дБ.
Подтверждено: шунт 10к даёт воспроизводимый дополнительный угол ≈10 Гц, эффект следует
за резистором. Оценки Rout SRPP ≈5–6 кОм и Rin(E-MU) ≈50–55 кОм понижены до статуса
