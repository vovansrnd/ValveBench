# План испытаний четырёхпозиционного переключателя выходной нагрузки

Этап: P0–P3 (пусто / 47к / 22к / 10к), по заданию координатора (см. CONTINUATION-HANDOFF.md).
Отдельные эксперименты с 33/47к прекращены. Текущая проводка до сборки переключателя,
зафиксировано оператором: **добавочный 10к + штатные 120к**.

## 1. Схема позиций (собирает оператор)

| Позиция | Добавочный шунт | Итого с 120к | Назначение |
|---|---|---|---|
| P0 | нет | 120к | референс, штатный режим |
| P1 | 47к | 120к∥47к | мягкая нагрузка |
| P2 | 22к | 120к∥22к | средняя |
| P3 | 10к | 120к∥10к | сильная (вход клиента 10к) |

- Штатные 120к **никогда не отключаются** (нет момента обрыва при переключении).
- Каждый добавочный резистор: от выходного узла после конденсатора 1,0 мкФ на сигнальную землю.
- Стерео: 2×47к, 2×22к, 2×10к, желательно 1% и попарно близкие; галетник переключает L и R одновременно.

## 2. Конфигурации входной нагрузки (имитация усилителя)

| Серия | Шунт на входе карты | Кто это |
|---|---|---|
| `rin10k` | 10 кОм | вход предусилителя клиента |
| `rin33k` | 33 кОм | второй сценарий |

Шунт входной нагрузки стоит у входа карты и не меняется в течение серии из 4 захватов.
**Вход E-MU 0404 подключён параллельно и не считается бесконечным** (рабочая гипотеза
≈50–60 кОм; уточняется отдельно, на карту позиций влияет как константа серии — в дельтах
P_x−P0 сокращается вместе с полюсом карты).

## 3. Матрица захватов (8 × 60 с, по готовности переключателя)

Команда каждого захвата:

```bash
./run.sh cli --rate 96000 noise-response --kind riaa --seconds 60 --level -36 --lo 2 --hi 1000 \
  --csv results/subsonic-experiment/captures/<имя>.csv
```

| Файл | Серия | Позиция |
|---|---|---|
| `rin10k_P0.csv` | 10к | P0 |
| `rin10k_P47k.csv` | 10к | P1 |
| `rin10k_P22k.csv` | 10к | P2 |
| `rin10k_P10k.csv` | 10к | P3 |
| `rin33k_P0.csv` | 33к | P0 |
| `rin33k_P47k.csv` | 33к | P1 |
| `rin33k_P22k.csv` | 33к | P2 |
| `rin33k_P10k.csv` | 33к | P3 |

Плюс на каждой позиции короткий тоновый замер для изменения усиления на 1 кГц
(CSV шумового захвата нормирован на 1 кГц и абсолютное усиление не несёт):

```bash
./run.sh cli --rate 96000 thd --f 997 --level -12
```

— фиксируем «вх АЦП dBFS» по L/R; разница между позициями = изменение усиления на 1 кГц.

## 4. Чек-лист перед запуском (оператор)

1. Мультиметром: фактические значения 6 резисторов (47/47, 22/22, 10/10), пары близкие.
2. Прозвонка: каждое положение замыкает L и R одновременно; 120к не рвутся ни в одном положении.
3. Входной шунт серии (10к или 33к) стоит на входе карты в обоих каналах.

## 5. Анализ (готов, скрипт `analysis/switch_map.py`)

- Оба канала в захвате одинаковы по схеме → кривая позиции = среднее (L+R)/2;
  отдельно фиксируется расхождение L/R как контроль пайки.
- Дельта позиции: P_x − P0 по средним кривым → однополюсная подгонка (6–200 Гц,
  coh≥0,50 и ≥0,70) = эффективный угол добавочной нагрузки. Полюс карты и входной шунт
  серии в дельте сокращаются.
- Таблица ослабления: 5 / 8 / 10 / 15 / 20 / 25 / 31,5 / 40 / 80 Гц, обе серии.
- Δ усиления на 1 кГц между позициями — из тоновых замеров.
- Вердикт: какие позиции дают полезное различие при входе 10к и 33к, какие дублируют
  (критерий: разница дельта-углов ≥ ~15–20% и ≥1 дБ ослабления в полосе 8–15 Гц).
- Достоверность по данным 11.3: 200–1000 Гц ±0,03 дБ; 20–45 Гц ±0,5–1 дБ; бины 48–52 Гц
  исключены (сеть). Все исходные CSV сохраняются без фильтрации.

## 6. Что НЕ делать в этой серии

- Не менять выходной конденсатор 1,0 мкФ и штатные 120к.
- Не трогать катодные 470 мкФ (следующий этап — отдельная серия 470/220 мкФ, АЧХ потом THD/H2/H3
  на одинаковом фактическом выходном уровне).
- Никаких внеплановых переключений: каждый захват отвечает на один вопрос.
